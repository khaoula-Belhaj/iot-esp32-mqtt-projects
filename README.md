# IoT Projects — ESP32, MQTT & Node-RED

End-to-end IoT projects from sensor to dashboard: ESP32 firmware in MicroPython, MQTT messaging, Node-RED supervision — with a focus on **reliability** (watchdog, interrupts, edge decisions) and **security** (broker authentication, TLS).

> Academic projects — IoT module, ENSA Fez (GSCSI).

| Project | Highlights |
|---|---|
| [**Smart Cold Chain**](smart-cold-chain/) | Vaccine-shipment monitoring: DHT22, MPU6050 (I2C), ADC battery, tamper interrupt, watchdog, RTC — full MicroPython firmware included |
| [**MQTT Security & QoS Lab**](mqtt-security-qos-lab/) | EMQX in Docker, authentication, plain MQTT vs TLS analysed in Wireshark, QoS 0/1/2, Node-RED control loop |
| [**AgroSmart Plant Monitoring**](agrosmart-plant-monitoring/) | Soil-moisture monitoring with local edge decisions (LED levels) and a Node-RED dashboard |
